# TRAJECTIQ v5 demonstration paths

These are suggested recording timings, not claims that a timed human rehearsal has passed. Record the actual game; do not replace outcomes with invented scores. Use Moon Balanced for the first beginner demonstration. See the scientific report for conditions behind numerical benchmarks.

## 90 seconds

| Time | Click / show | Explain |
|---|---|---|
| 0–12s | Mission offer → Accept mission | “We turn mission design into decisions whose consequences you can measure. The objective is to return520 science units within150 fictional credits.” |
| 12–27s | Choose Science payload; compare camera and imager; return to Balanced | “More detailed science also demands more mass, power, storage and bandwidth. The margins update from the same engine that flies the mission.” |
| 27–40s | Launch readiness → Authorize launch | “Blockers stop launch. Warnings are trade-offs the player must manage.” |
| 40–57s | Next event; respond to the actual displayed crisis; repeat as needed | “A crisis pauses the clock. The assistant can simulate enabled choices from this exact state.” |
| 57–72s | Complete mission → debrief | “Only observations returned to Earth count. The debrief connects the decision to energy, data and science consequences.” |
| 72–82s | Redesign → Apply power+comms fix preview | “An upgrade shows before/after costs and preserves unrelated custom choices.” |
| 82–90s | Sources, then destination selector | “NASA/JPL constants drive the Moon and Mars environments. Hardware, costs and scenarios are openly labeled teaching assumptions.” |

If a crisis or finish takes longer, shorten the component demonstration rather than concealing an unfinished flight. Preflight the exact path on the recording machine.

## Three minutes

| Time | Interaction and teaching point |
|---|---|
| 0–20s | Introduce team, objective and complete design-to-redesign loop. Accept mission. |
| 20–50s | Show payload choice and live mass/power/data margins. Customize battery125%; explain that larger batteries add mass/cost rather than creating free energy. Return to a chosen documented design. |
| 50–75s | Read readiness checks, authorize launch, show compressed schematic transfer/capture. Explicitly call it an educational orbital mission, not a full trajectory solver. |
| 75–110s | Advance to an actual crisis. Ask assistant to preview choices, close it, choose one and resume. Explain what changed using displayed numbers. |
| 110–135s | Finish and read causal debrief, actual returned units, target percentage, retained/lost data and final battery. Distinguish full progress bar from above100% raw attainment. |
| 135–155s | Show targeted redesign preview. Keep orbit/payload/fuel fixed. Compare common-policy assistant forecasts or label saved human-run differences as observational. |
| 155–170s | Select Mars after completion. Show lower solar flux and destination-specific orbit/distance constraints. State that transport is pre-arranged and link hardware is fictional. |
| 170–180s | Open Sources. Close with the educational purpose and offline accessibility. |
